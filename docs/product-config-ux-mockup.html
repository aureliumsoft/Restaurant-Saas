How to read this mockup Amber “was classic only” badges = options that exist in the classic editor today but not in the live guided wizard. This file is a design target — not wired to the app yet. Backend stays the same; we only change how we ask.

Checklist — classic → this mockup

Every gap from the classic editor is placed somewhere in the flow above:

  1. Product · single → step “What are they choosing?” → One specific product option
  2. Product · multiple → Specific products (pick several)
  3. Multi-category in one rule → category checkboxes (pick several)
  4. Category discount % → More pricing → Category discount
  5. Recommended variation → More pricing → Recommended size
  6. Show recommended variation price → toggle under recommended size
  7. Default item → More pricing → Default item
  8. Price by product variation → “Price add-ons by pizza size”
  9. Free quantity → appears when Plus/minus is selected
  10. No free items → toggle next to free quantity
  11. Free quantity (product rules) → same panel when product kind is selected
  12. No free items (product) → same toggle
  13. Per-size min/max → “Different min / max per pizza size”
  14. Per-linked-product min/max → “Limits per linked product” list
  15. Personalize max selections → Maximum selections field
  16. Option photos → Photo buttons on each preference
  17. Multi-group personalize → “Add another preference group”
  18. Edit / remove preference groups → Remove group + remove option links
